# Amazon チャネルルール

## 基本分析（CORE ANALYSISを適用）

楽天と共通の基本思想：集客・CVR・客単価・商品・広告・SEO・レビュー・在庫・利益

## Amazon固有の指標

| 指標 | 説明 |
|------|------|
| BSR | ベストセラーランキング（カテゴリ順位） |
| A+ | Aプラスコンテンツ（ブランドページ） |
| FBA在庫 | FBA倉庫の在庫数・補充リードタイム |
| ACOS | 広告費 / 広告経由売上 × 100（Advertising Cost of Sale） |
| TACOS | 広告費 / 総売上 × 100（Total ACOS） |
| SP広告 | スポンサープロダクト広告 |
| SB広告 | スポンサーブランド広告 |
| SD広告 | スポンサーディスプレイ広告 |

## Amazon固有の分析ポイント

### Buy Box
- Buy Box獲得率が低い場合は価格・FBA利用・出品者評価を確認
- Buy Box獲得率 < 80%の場合はP1対応

### レビュー
- 評点3.5未満はCVRに大きく影響
- 評点4.0以上を維持することを目標とする
- Vineプログラムの活用検討

### 在庫（FBA）
- FBA在庫切れはBSRの急落を招く
- 補充リードタイム（製造・配送）を考慮した発注ルール設定が必須

## データ取得元

- 売上・注文：セラーセントラル → レポート → ビジネスレポート
- 広告：広告コンソール → キャンペーンマネージャー
- 在庫：セラーセントラル → 在庫 → 在庫管理
