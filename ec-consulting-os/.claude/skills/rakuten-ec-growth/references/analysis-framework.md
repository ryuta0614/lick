# 分析フレームワーク — 手順と計算式

## 1. 売上変動分析

### 手順
1. **比較期間の設定**
   - 前月比（同月曜日・祝日・イベント補正後）
   - 前年同月比（季節性を排除した比較）
   - 計画比（設定している場合）
   - イベント期と通常期を必ず分離して比較

2. **KPI変動の数値確認**
   - 売上・アクセス・CVR・客単価・利益の前期比を算出
   - 各KPIの変動方向と幅を確認

3. **寄与度分解**
   ```
   アクセス要因 = (今期アクセス - 前期アクセス) × 前期CVR × 前期AOV
   CVR要因 = 今期アクセス × (今期CVR - 前期CVR) × 前期AOV
   AOV要因 = 今期アクセス × 今期CVR × (今期AOV - 前期AOV)
   ```

4. **商品レベルへの展開**
   - 全商品の前期比売上を算出
   - 売上増加商品・減少商品を特定
   - 各商品のアクセス・CVR・客単価の変動を確認

5. **商品別売上寄与分析**
   ```
   商品Xの寄与額 = 商品X今期売上 - 商品X前期売上
   商品Xの寄与率 = 商品X寄与額 / 前期総売上 × 100
   ```

## 2. 商品診断マトリクス（2×2）

### マトリクス定義

アクセス数（横軸）と CVR（縦軸）で全商品を4象限に分類する。
閾値は店舗平均または上位商品群の中央値を基準とする。

```
               アクセス 低         アクセス 高
CVR 高    │  B: 露出不足商品  │  A: 主力商品     │
CVR 低    │  D: 投資優先度低  │  C: 最重要改善商品│
```

### 各象限の解釈と施策方針

**象限A（主力商品）: アクセス高 × CVR高**
- 現状: 店舗の収益の柱。売上・粗利ともに上位
- リスク: 在庫切れ・競合台頭・SEO順位低下
- 施策方針:
  - RPP拡大（予算上限を引き上げる）
  - SEO維持・強化（商品名・KW）
  - 在庫積み増し（欠品リスク排除）
  - バリエーション拡充・上位モデル導入
  - クロスセル・セット化による客単価向上
  - 高単価バリエーション訴求

**象限B（露出不足商品）: アクセス低 × CVR高**
- 現状: 見てもらえれば買われる商品。集客が課題
- 機会: アクセスを増やすだけで売上が伸びる
- 施策方針:
  - RPP強化（優先的に広告費配分）
  - SEO改善（商品名・キャッチコピーへのKW追加）
  - 検索KW拡張（関連KW・用途KW・悩みKW）
  - カテゴリ設定の見直し
  - イベント時の露出強化（ランキング対策）

**象限C（最重要改善商品）: アクセス高 × CVR低**
- 現状: 集客できているが売れていない。最も損失が大きい象限
- 優先度: 最高（改善効果が即座に売上に直結）
- CVR低下の15確認項目:
  1. 流入KWと商品の検索意図ミスマッチ
  2. 競合比較での価格競争力
  3. 商品画像の品質・枚数
  4. 商品説明の情報量・訴求力
  5. レビュー数・平均評価（3.5未満は要注意）
  6. 在庫状況（SKU単位の部分欠品）
  7. 送料条件（送料無料閾値）
  8. クーポン・ポイント有無
  9. チャネル別CVR差（RPP vs 自然検索 vs ランキング）
  10. スマホ/PC差（スマホ最適化の有無）
  11. 価格変更のタイミング
  12. SALE前後のCVR変動
  13. 競合の新商品・値下げ
  14. 季節性・需要変動
  15. 商品ページの技術的問題（表示崩れ等）

**象限D（投資優先度低）: アクセス低 × CVR低**
- 現状: アクセスも少なく、見ても買われない商品
- 基本方針: 原則として積極投資は行わない
- 例外ケース（投資継続を検討）:
  - 新商品で立ち上げ初期（3ヶ月以内）
  - 季節性商品のオフシーズン期間
  - 戦略的ラインナップ維持が必要な商品
  - 改善施策の仮説が明確にある場合

## 3. ABC分析

### 5種類のABC分析を別々に実施

売上ABCだけでは意思決定を誤る。5種類を並べて総合判断する。

| 種別 | 指標 | 目的 |
|------|------|------|
| 売上ABC | 商品別売上金額 | 収益貢献の把握 |
| 粗利ABC | 商品別粗利金額 | 実利益貢献の把握 |
| アクセスABC | 商品別セッション数 | 集客力の把握 |
| 新規獲得ABC | 商品別新規顧客獲得数 | 入口商品の特定 |
| リピートABC | 商品別リピート件数 | 定番商品の特定 |

### 分類基準
- A: 上位 70%（通常は全SKUの10〜20%）
- B: 70〜90%（全SKUの20〜30%）
- C: 下位 10%（全SKUの50〜70%）

### 複合パターンの解釈
| 売上 | 粗利 | 新規獲得 | 解釈 |
|------|------|---------|------|
| A | A | A | 完全主力商品。在庫・品質維持が最優先 |
| A | C | A | 売れているが利益が薄い。価格・広告・値引見直し |
| B | A | B | 高粗利商品。アクセス増やすだけで利益改善 |
| C | C | A | 入口商品。LTVで判断。F2施策が重要 |
| A | A | C | 既存顧客向け定番。リピーター維持施策 |

## 4. RFM分析

### セグメント定義

| セグメント | Recency | Frequency | Monetary | 施策方針 |
|-----------|---------|-----------|---------|---------|
| VIP顧客 | 直近3ヶ月以内 | 5回以上 | 上位20% | 特別扱い・先行情報提供・個別対応 |
| 優良顧客 | 直近3ヶ月以内 | 3〜4回 | 中位 | ポイント・特典でロイヤリティ強化 |
| 成長顧客 | 直近3ヶ月以内 | 2回 | 中位 | F3への転換促進 |
| 新規顧客 | 直近1ヶ月 | 1回 | - | F2転換が最優先。フォローメール |
| 休眠予備 | 3〜6ヶ月未購入 | 2回以上 | 中〜高 | 再活性化クーポン・限定情報 |
| 休眠顧客 | 6ヶ月以上未購入 | - | - | 強いインセンティブでの復帰施策 |

### 算出方法
```
R（Recency）= 最終購入日から分析基準日までの日数（少ない=良い）
F（Frequency）= 集計期間内の購入回数
M（Monetary）= 集計期間内の累計購入金額

各指標を5段階スコアに変換して組み合わせる
```

## 5. バスケット分析

### 目的
同一注文で一緒に購入されやすい商品ペアを発見し、クロスセル施策に活用する。

### 指標計算
```
Support（支持度）= 商品AとBを同時購入した注文数 / 全注文数
  → 施策の対象規模を示す（Support低=ニッチな組み合わせ）

Confidence（信頼度）= 商品AとBを同時購入した注文数 / 商品Aを含む注文数
  → Aを買った人がBも買う確率

Lift（リフト値）= Confidence / Bを含む注文の割合
  → Lift > 1.0 でランダムより組み合わせ購入が多い
  → Lift > 2.0 で強い相関、クロスセル施策の有力候補
```

### 活用方法
- Lift上位ペアをセット商品として登録
- 商品ページの「一緒に購入されている商品」に掲載
- まとめ買い割引の設計に活用

## 6. F2/F3転換分析

### 転換率の測定
```
F2転換率（30日）= 初回購入から30日以内に2回目購入した顧客数 / 初回購入顧客数 × 100
F2転換率（60日）= 同60日
F2転換率（90日）= 同90日（楽天標準）
F2転換率（180日）= 同180日
F2転換率（365日）= 同365日（LTV測定用）

F3転換率（90日）= F2顧客のうち90日以内にF3転換した割合
```

### 分析の注意点
- コホート分析が基本（初回購入月別に追跡）
- イベント期初回購入者と通常期を分けて比較
- 初回購入商品別にF2転換率を比較する（入口商品の評価に使用）

## 7. 購入周期分析

```
購入間隔（中央値）= 2回目以降の購入者について、前回購入からの日数を算出し中央値を取る

再購入タイミング施策の設計:
  購入間隔の中央値 × 0.8 = リマインドメールのタイミング
  購入間隔の中央値 × 1.2 = 再購入促進クーポン配布のタイミング
```

## 8. LTV分析

### LTV計算
```
LTV（売上）30日 = コホート内顧客の30日累計売上 / コホート顧客数
LTV（売上）60日 = 同60日
LTV（売上）90日 = 同90日
LTV（売上）180日 = 同180日
LTV（売上）365日 = 同365日

LTV（粗利）= LTV（売上） × 粗利率

新規獲得CPO（許容値）= LTV（粗利）× 許容回収率
  ※ 許容回収率は店舗のキャッシュフロー戦略による（通常30〜50%）
```

### 初回購入商品別LTV比較
どの商品を入口として獲得した顧客が長期的に高LTVになるかを分析する。
RPPの入口商品選定・SEO注力商品の選定に活用。

## 9. 価格弾力性分析

```
価格弾力性 = (CVR変化率) / (価格変化率)

例:
  価格 +10% → CVR -15% の場合
  弾力性 = -15% / 10% = -1.5
  → 弾力性 < -1: 価格感応度が高い（値下げが有効）
  → 弾力性 > -1: 価格感応度が低い（値上げ余地あり）
```

### 分析の注意
- 価格変更前後の期間を揃える（最低2週間ずつ）
- イベント期間は除外する
- 季節変動・競合変化を補正する

## 10. 機会損失の金額化

### CVR改善機会
```
CVR改善機会（売上）= アクセス数 × (目標CVR - 現CVR) × 客単価
CVR改善機会（利益）= CVR改善機会（売上）× 粗利率

目標CVR = 同カテゴリ商品群の上位25%CVR or 自社ベスト時期のCVR
```

### SEO機会
```
SEO改善機会（売上）= 想定追加アクセス数 × 現CVR × 客単価
想定追加アクセス数 = 対象KWの推定月間検索数 × 目標順位クリック率 - 現流入数

順位別クリック率の参考値:
  1位: 30〜35%, 2位: 15〜20%, 3位: 10〜12%, 5位: 5〜7%, 10位: 2〜3%
```

### 欠品損失
```
欠品機会損失（売上）= 通常日販（個） × 欠品日数 × 平均単価
欠品機会損失（利益）= 欠品機会損失（売上）× 粗利率

通常日販 = 欠品前30日の平均日次販売数（欠品期間のデータは除外）
```

### 客単価改善機会
```
AOV改善機会（売上）= 月次注文件数 × (目標AOV - 現AOV)
AOV改善機会（利益）= AOV改善機会（売上）× 粗利率
```

### F2転換改善機会
```
F2改善機会（売上）= 期間内新規顧客数 × (目標F2転換率 - 現F2転換率) × F2客単価
F2改善機会（利益）= F2改善機会（売上）× 粗利率

目標F2転換率 = 業界参考値 or 自社ベスト期実績
```
