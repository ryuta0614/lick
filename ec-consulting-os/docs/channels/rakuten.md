# 楽天市場 チャネルルール

## 分析必須項目

### 売上
- 売上 / 注文件数 / 客単価
- 新規 / 既存 / リピート別

### 集客
- アクセス / UU
- 検索流入 / RPP / TDA等 / 外部流入 / 指名検索

### CVR
- 店舗CVR / 商品別CVR / デバイス別CVR

### 商品・SKU
- SKU別：売上 / アクセス / CVR / 客単価 / 利益 / 在庫

### SEO
- 検索キーワード / 検索順位 / 流入キーワード
- 商品名 / キャッチコピー / タグ / JAN / 属性情報

### 販促
- クーポン / ポイント / スーパーSALE / マラソン / 5と0のつく日
- 値引 / セット販売 / まとめ買い

### 広告
- RPP / TDA等
- キーワード別：CPC / CTR / CVR / CPA / ROAS / 利益

### レビュー
- 件数 / 評点 / ポジネガ / 購入理由 / 不満 / 改善要求

### 競合
- 価格 / ポイント / クーポン / レビュー / 商品ページ / SEO / ランキング

## 楽天固有の指標

| 指標 | 説明 |
|------|------|
| RPP費 | 楽天商品検索広告費 |
| SPU | 楽天スーパーポイントアッププログラムによるポイント倍率 |
| ランキング順位 | カテゴリ・ジャンル別ランキング順位 |
| 楽天ポイント原資 | ポイント付与に対する自社負担額 |

## イベント対応チェックリスト

| イベント | 事前確認項目 |
|----------|-------------|
| スーパーSALE | クーポン設定 / 目玉商品在庫 / ページ更新 |
| お買い物マラソン | エントリー商品 / ポイント設定 / 広告予算 |
| 5と0のつく日 | 広告入札調整 / 在庫確認 |

## データ取得元

- 売上・注文：RMS → 売上管理 → 売上レポート
- アクセス：RMS → アクセス分析
- 広告：RMS → 広告 → RPP管理
- 検索：RMS → SEO → 検索キーワード分析
