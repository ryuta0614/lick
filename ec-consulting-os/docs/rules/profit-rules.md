# 利益判断ルール

## 利益計算の基本式

```
限界利益 = 売上 - 原価 - 広告費 - 値引額 - ポイント原資 - 送料 - モール手数料
限界利益率 = 限界利益 / 売上 × 100
```

## 広告施策の判断基準

| 判断 | 条件 |
|------|------|
| 増額 | 限界利益がプラス かつ 在庫十分 かつ ROASが目標以上 |
| 継続 | 限界利益がプラス かつ ROASが目標前後 |
| 改善 | ROASが目標以下だが改善余地あり（CVR・CPC・キーワード） |
| 減額 | 限界利益がマイナス または 在庫少量 |
| 停止 | 限界利益が大幅マイナス または 在庫欠品リスク |
| テスト | 新規施策で実績不明 |

目標ROASは案件ごとに `clients/{client}/context/config.json` で設定する。

## 値引・クーポン施策の判断基準

値引施策を評価する際は以下を確認する：

1. 値引後の粗利率が閾値（デフォルト20%）を下回っていないか
2. 値引による売上増加が値引コストを上回っているか
3. 値引後のROASは改善しているか
4. リピート購入への影響はあるか（安売り慣れのリスク）
