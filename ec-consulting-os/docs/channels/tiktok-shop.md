# TikTok Shop チャネルルール

## 分析必須項目

- GMV / 注文 / CVR
- 商品別売上
- 動画経由 / LIVE経由 / 商品カード経由
- 広告 / クリエイター / Affiliate / サンプル
- 投稿本数 / 動画再生 / CTR / CVR
- クリエイター別成果
- LIVE時間 / LIVE時間あたりGMV
- キャンセル / 返品
- 手数料 / 粗利

## 運営WBSテンプレート

```
商品登録
→ クリエイター募集（アフィリエイト）
→ サンプル発送
→ 投稿（動画）
→ LIVE配信
→ 広告投下（VSA等）
→ 数値検証（GMV / CVR / クリエイター別）
→ 継続 / 増額 / 撤退判断
```

## TikTok Shop固有の指標

| 指標 | 説明 |
|------|------|
| GMV | Gross Merchandise Value（流通総額） |
| LIVE_GMV | LIVE配信中の購入総額 |
| GMV/LIVE時間 | LIVE効率の基本指標 |
| Creator件数 | アフィリエイトクリエイター登録数 |
| Affiliate売上比率 | GMV中のアフィリエイト経由割合 |
| VSA | Video Shopping Ads（動画広告） |

## クリエイター評価基準

| 評価 | 条件 |
|------|------|
| 継続・追加発注 | CVR 3%以上 かつ GMV 10万円以上/投稿 |
| 様子見 | CVR 1〜3% または GMV 3〜10万円/投稿 |
| 撤退 | CVR 1%未満 かつ GMV 3万円未満/投稿 |

## LIVE配信評価基準

| 評価 | 条件 |
|------|------|
| 増枠 | GMV/LIVE時間 10万円以上 |
| 維持 | GMV/LIVE時間 5〜10万円 |
| 改善 | GMV/LIVE時間 5万円未満（商品・演出・配信者を見直し） |
