# 在庫判断ルール

## 在庫分類（デフォルト閾値）

閾値は `clients/{client}/context/config.json` で案件ごとに上書き可能。

| 分類 | 在庫日数 | 対応方針 |
|------|----------|----------|
| 超滞留在庫 | 180日以上 | 大幅値下げ・アウトレット・セット・卸・終売 |
| 滞留在庫 | 90〜179日 | LP改善・広告・SEO・クーポン・セット |
| 要注意在庫 | 60〜89日 | 追加集客・露出強化 |
| 健全在庫 | 30〜59日 | 維持・追加仕入れ検討 |
| 少量在庫 | 30日未満 | 欠品予測・広告抑制・入荷判断 |

## 在庫別施策テンプレート

### 超滞留在庫（180日以上）
1. 大幅値下げ（原価以上を確保できる範囲で最大値引き）
2. アウトレットページ作成
3. 他商品とのセット販売
4. 同梱施策（購入者へのサービス品）
5. 卸・業販チャネル開拓
6. 外部チャネル（メルカリ、Yahoo!フリマ等）
7. 終売・廃棄の判断

### 滞留在庫（90〜179日）
1. 商品ページ・LPの改善
2. 広告増額（在庫消化まで許容CPA引き上げ）
3. SEO対策（キーワード見直し）
4. クーポン発行
5. セット・まとめ買い設計

### 少量在庫（30日未満）
1. 欠品予測日を計算して仕入れ担当に通知
2. 広告費を段階的に抑制
3. RPP等の自動入札上限を下げる
4. 入荷確定まで売上予測を保守的に修正

## 在庫計算方法

```
在庫日数 = 現在庫数 / 直近30日の日次平均販売数
日次平均販売数 = 直近30日の販売数 / 30
```

季節商品の場合は直近30日ではなく前年同期を参照する。
