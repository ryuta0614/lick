# データディクショナリ — 楽天RMSエコシステム

## データソース一覧とJOINキー

### 主要JOINキー
| キー名 | 説明 | 使用データ |
|--------|------|-----------|
| 日付（YYYY-MM-DD） | 日次データの結合軸 | 全日次データ |
| 商品管理番号 | RMS上の商品ID（SKUを束ねる親ID） | 商品・広告・在庫・注文 |
| SKU番号 | バリエーション単位のID | 在庫・注文明細 |
| 注文番号 | 注文レコードの一意識別子 | 注文・顧客 |
| 顧客ID（楽天会員ID） | 購買履歴の紐付け | 注文・CRM |
| キャンペーンID | クーポン・ポイントキャンペーンの識別 | 販促・注文 |

## データソース詳細

### 1. 店舗売上データ（日次/月次）

**取得元**: RMS > データ分析 > 売上レポート

| 項目名 | 定義 | 単位 | 粒度 |
|--------|------|------|------|
| 売上金額 | 税込売上高（キャンセル前） | 円 | 日次/月次 |
| 売上件数 | 注文件数（キャンセル前） | 件 | 日次/月次 |
| セッション数（アクセス数） | ユニーク訪問者数（店舗TOP含む） | UU | 日次 |
| ページビュー | 全ページのPV合計 | PV | 日次 |
| 転換率（CVR） | 売上件数 / セッション数 × 100 | % | 日次 |
| 客単価（AOV） | 売上金額 / 売上件数 | 円/件 | 日次/月次 |
| キャンセル件数 | キャンセルされた注文件数 | 件 | 日次/月次 |
| 返品件数 | 返品処理された件数 | 件 | 月次 |
| 新規顧客数 | 初回購入顧客数 | 人 | 月次 |
| リピーター数 | 2回以上購入顧客数 | 人 | 月次 |

**注意**: 楽天のCVRはPVではなくセッション（UU）ベース。他モールとは計算基準が異なる。

## データ品質 3段階評価

### 評価基準

| 評価 | ラベル | 条件 | 分析への影響 |
|------|--------|------|-------------|
| ○ | 分析続行可能 | 欠損5%未満、期間3ヶ月以上、主要KPIが揃っている | 通常通り分析可能 |
| △ | 注意が必要 | 欠損5〜30%、期間1〜3ヶ月、一部KPIが欠落 | 分析可能だが結論に留保を付ける |
| × | 分析不可 | 欠損30%超、期間1ヶ月未満、主要KPIが揃わない | 当該分析は実施不可。必要データを明示 |

### よくあるデータ品質問題

| 問題 | 影響 | 対処 |
|------|------|------|
| 欠品期間の売上データ | CVR・需要を過小評価 | 欠品期間をフィルタして別途評価 |
| イベント期間の混在 | CVR・客単価の歪み | イベントフラグで分離 |
| キャンセル前売上のみ | 実売上の過大評価 | キャンセル率を確認し補正 |
| 顧客IDの欠落 | RFM・F2分析不可 | 注文データから再構成を試みる |
| 原価データなし | 粗利計算不可 | 粗利率仮定で試算、明示する |
| RPP期間が限定的 | 広告効果の誤判断 | 最低4週間以上のデータを推奨 |
| 商品追加・廃番 | 時系列比較が歪む | 共通商品のみでの比較を実施 |
