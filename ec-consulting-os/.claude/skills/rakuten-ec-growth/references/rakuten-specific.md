# 楽天固有分析ルール

## 1. RPP広告分析

### RPP分析チェーン
RPP効果を評価する際は、以下のファネル全体を確認する:

```
インプレッション（表示）
    ↓ CTR（クリック率）
クリック数
    ↓ 広告CVR
広告経由注文数
    ↓ 商品単価
広告売上
    ↓ 粗利率
広告粗利
    ↓ 新規率
新規顧客獲得数
    ↓ F2転換率・LTV
顧客生涯価値
```

単一の指標（ROAS・CTRなど）だけで評価せず、チェーン全体の健全性を確認する。

### RPP診断マトリクス

| 症状 | 原因候補 | 対策 |
|------|---------|------|
| インプレッション（表示）が少ない | 入札単価が低い / 予算枯渇 / 商品の品質スコア低 | 入札単価引き上げ・予算増額・商品ページ改善 |
| CTRが低い（業界平均比） | 商品画像が競合に劣る / 価格競争力が弱い / 商品名が訴求不足 | サムネイル画像改善・価格見直し・商品名KW追加 |
| 広告CVRが低い | 流入KWと商品のミスマッチ / 商品ページが弱い / 価格設定 | KW絞り込み・ページ改善・競合価格調査 |
| ROAS低 × LTV高 | 入口商品として機能 → 単純なROAS改善は不可 | LTVベースの許容CPA設定で継続判断 |
| ROAS低 × LTV低 | 広告効率が悪く、リピートも少ない | 入札単価削減・対象KW絞り込み・商品見直し |
| 予算が途中で枯渇 | ROAS高い状態で機会損失発生 | 予算上限の引き上げ（P0対応） |

### ROAS目標値の設定方法
```
最低限のROAS（損益分岐）= 1 / 粗利率 × 100

例: 粗利率30%の場合
  損益分岐ROAS = 1 / 0.30 × 100 = 333%
  ※ これを下回ると広告による粗利がマイナス

新規獲得を考慮したROAS目標（LTVベース）:
  許容CPO = LTV（粗利・90日） × 許容回収率（30〜50%）
  目標ROAS = 商品単価 / 許容CPO × 100
```

## 2. 楽天SEO分析

### 楽天検索KWの分類
全ての商品についてターゲットKWを以下の分類で整理する:

| KW分類 | 例 | 特徴 |
|--------|-----|------|
| Big KW（カテゴリ名） | 「プロテイン」「スニーカー」 | 検索数多・競合強・CVR低め |
| Middle KW（商品属性） | 「プロテイン ホエイ」「スニーカー 白 メンズ」 | バランス型 |
| Long-tail KW（具体的） | 「プロテイン 3kg 大容量 無添加」 | 検索数少・CVR高め・競合少 |
| 用途・シーンKW | 「プロテイン 朝食 置き換え」「スニーカー 通勤 疲れにくい」 | 需要明確・転換率高 |
| 悩みKW | 「プロテイン 飲みやすい 初心者」「足 痛い スニーカー」 | 課題解決型 |
| 属性KW | 「プロテイン 女性向け」「スニーカー 幅広」 | セグメント特化 |
| ギフトKW | 「プロテイン ギフト 父の日」「スニーカー プレゼント」 | 季節・ギフト需要 |
| 季節KW | 「プロテイン 夏 暑い 溶けやすい」 | 時期限定だが集中需要 |
| ブランドKW | 「BRAND名 プロテイン」 | ブランド認知がある場合 |

### SEO改善の優先度
1. **商品名（最重要）**: Big KW + Middle KW + 主要属性を含める（最大100文字程度）
2. **キャッチコピー**: 追加KW・ギフト・悩み系KWを含める
3. **検索KW設定（RMSの「商品説明」フィールド）**: Long-tail・シーンKWを追加
4. **商品説明文**: 検索KWを自然な文章に含める

### SEO改善前の確認事項
- 現在の検索流入KW一覧（上位20KW以上）
- 各KWでの現在順位
- 競合商品の商品名・KW分析
- 改善候補KWのコンペ状況

## 3. 楽天イベント分析

### イベント増分売上の計算
```
イベント増分売上 = イベント期間実績売上 - 通常期間期待売上

通常期間期待売上 = イベントなし直前2週間の日次売上平均 × イベント期間日数

イベント増分利益 = イベント増分売上 × 粗利率
              - イベント追加ポイント原資
              - イベント向けクーポン値引
              - 広告費増加分
```

### イベント依存度の評価
```
イベント依存率 = イベント期間売上 / 全期間売上 × 100

評価基準:
  〜30%: 健全。通常日の集客・販売力がある
  30〜50%: 要注意。通常日強化の余地あり
  50%超: 構造的リスク。イベント頼みの体質
```

### イベント効果の商品別分析
- どの商品がイベント期に特に伸びるか（イベント向け商品の特定）
- イベント期のみ購入の顧客とリピート購入顧客を分けて分析
- イベント期に獲得した新規顧客のF2転換率（通常期獲得と比較）

### イベント計画策定
- SALE価格・クーポン・ポイント設定の締め切り確認
- 在庫の事前積み増し計画（欠品=機会損失）
- 広告予算のイベント期集中配分
- 販促コスト（値引+ポイント+広告）の利益シミュレーション実施

## 4. クーポン分析

### クーポン効果の評価指標
```
クーポン利用率 = 利用件数 / 発行枚数 × 100
クーポン起因売上 = クーポン利用注文の売上合計
クーポンROI = (クーポン起因増分売上 - 値引コスト) / 値引コスト × 100
新規獲得効果 = クーポン利用新規顧客数 / 新規顧客数全体 × 100
```

### クーポン種別の効果比較

| クーポン種別 | 主な効果 | 注意点 |
|------------|---------|--------|
| 金額引きクーポン（例: 500円引） | 明確な割引感。コンバージョン効果高 | 高額商品で値引率が小さく見える |
| 率引きクーポン（例: 10%引） | 高額商品で効果的 | 低額商品では心理的効果が小さい |
| 送料無料クーポン | 送料が障壁になっている場合に効果的 | 送料が気にならない顧客には効果薄 |
| 閾値クーポン（例: 3000円以上で500円引） | 客単価向上効果 | 閾値の設定が重要（AOVの110〜130%） |

### クーポン設計の原則
- **新規向け**: 初回購入の心理的ハードルを下げる（大きめの値引き）
- **F2向け**: 初回購入から適切なタイミングで送付（購入周期×0.8日後）
- **休眠向け**: 最終購入から一定期間後に強いインセンティブ
- **閾値設定**: 現在の客単価 × 1.15〜1.30が効果的な閾値

## 5. ポイント分析

### ポイント効果の評価
```
ポイント原資率 = ポイント原資合計 / 売上 × 100
  ※ 通常1%（楽天基本ポイント）+ 店舗追加分

ポイント増分ROAS = ポイントキャンペーン期間の増分売上 / ポイント追加原資
```

### ポイント倍率別効果分析
- 倍率1倍（基本）: ベースラインCVRの確認
- 倍率2〜5倍: CVR・客単価の変化率
- 倍率10倍以上: 集中需要の発生確認

### 過剰ポイント投資の検出
```
ポイント投資対効果 = (増分売上 × 粗利率) / 追加ポイント原資
  > 1.0: ポイント投資の回収ができている
  < 1.0: ポイント投資が過剰（赤字）
```

## 6. R-Mail（楽天メルマガ）分析

### R-Mail効果指標
```
開封率 = メール開封数 / 配信数 × 100
クリック率（CTR）= クリック数 / 開封数 × 100
転換率 = メール経由購入数 / クリック数 × 100
メール経由売上 = メール経由購入の売上合計
メールROI = (メール経由売上 × 粗利率) / 配信コスト × 100
```

### R-Mail改善のポイント
- 件名の最適化（A/Bテスト）
- 配信タイミング（購入周期に連動したタイミング配信）
- セグメント別配信（RFMセグメント別にコンテンツを変える）
- 商品訴求（購入商品に関連する商品の紹介）

## 7. 値引依存度分析

### 値引依存度の計算
```
値引依存度 = (SALE値引額 + クーポン値引額 + ポイント原資額) / 売上 × 100

内訳:
  SALE値引率 = (通常価格 - SALE価格) × SALE販売数 / 売上全体
  クーポン値引率 = クーポン値引額計 / 売上
  ポイント原資率 = ポイント付与額計 / 売上
```

### 値引依存度の評価
| 値引依存度 | 評価 | 対応 |
|-----------|------|------|
| 〜15% | 健全 | 現状維持・売上向上施策に集中 |
| 15〜25% | 普通 | 値引の効率を定期的に評価 |
| 25〜35% | 要注意 | 値引依存の商品・施策の見直し |
| 35%超 | 警戒 | 値引依存の脱却計画が必要 |

## 8. スマホ/PC差の分析

楽天では購入の7〜8割がスマートフォン経由。スマホ体験の最適化は最重要。

### 確認する指標
```
スマホCVR vs PCCVRの差
スマホ客単価 vs PC客単価の差
スマホ離脱率（商品ページ→購入）
```

### 改善チェックリスト
- [ ] スマホでの商品画像の視認性（スワイプで確認できるか）
- [ ] 商品名・価格・購入ボタンがファーストビューに収まっているか
- [ ] テキストのフォントサイズが読みやすいか
- [ ] ページ表示速度（重い画像がないか）
- [ ] サイズガイド・詳細情報のアコーディオン展開

## 9. ランキング効果分析

### ランキング掲載の効果
```
ランキング経由流入増 = ランキング掲載期間の流入 - 掲載前の流入
ランキング起因売上 = ランキング経由流入増 × CVR × 客単価
```

### ランキング対策のポイント
- 対象カテゴリランキングの確認（毎時更新）
- ランキング掲載中の在庫確保（欠品=ランキング落ちのリスク）
- イベント期のランキング入りのための販促計画
- ランキングページ自体はCVRが高い傾向があるため、掲載維持の価値が大きい
