# コンサルティング原則

## 1. レポートを作ることを目的にしない

最終目的は売上・利益・LTV・在庫効率・顧客成果を改善すること。

すべての分析は以下まで落とす：

```
事実 → 変化 → 原因 → 課題 → 優先順位 → 施策 → 担当 → 期限 → 成果物 → KPI
```

## 2. 売上構造の基本分解

**売上 = アクセス × CVR × 客単価**

売上が悪い場合、まずどこに問題があるか分解する：

### アクセス低下の原因ツリー
- 検索流入（SEO順位低下、キーワード変化）
- 広告流入（RPP、TDA等の効率低下）
- SNS流入
- 指名検索
- モールイベント対応
- 外部流入

### CVR低下の原因ツリー
- 商品ページの質
- 価格競争力
- クーポン・ポイント設計
- レビュー件数・評点
- 在庫状況（欠品）
- 配送条件
- 競合の動き
- 商品力
- 流入キーワードとのミスマッチ

### 客単価低下の原因ツリー
- 商品構成の変化
- セット販売・まとめ買い設計
- クロスセル・アップセル
- 送料無料ライン設計
- クーポン設計の影響

## 3. 利益を必ず見る

売上施策・広告施策・値引施策を評価する際は以下をすべて確認する：

| 指標 | 説明 |
|------|------|
| 売上 | 純売上 |
| 粗利 | 売上 - 原価 |
| 粗利率 | 粗利 / 売上 |
| 広告費 | RPP・TDA等の合計 |
| ROAS | 売上 / 広告費 |
| CPA | 広告費 / 注文件数 |
| 限界利益 | 粗利 - 広告費 - 値引 - ポイント原資 - 送料 - 手数料 |
| 在庫回転 | 期間売上 / 平均在庫 |

**ROASが高い＝良い施策ではない。**

## 4. 比較軸

数値は単月だけで判断しない。可能な範囲で以下で比較する：

- 目標比 / 前月比 / 前年比
- 3ヶ月推移 / 6ヶ月推移
- 商品別 / SKU別 / チャネル別
- 新規・既存別
- 広告別 / キーワード別
- デバイス別 / 流入別

数字が変化した場合は**寄与度**で説明する。

## 5. 事実と仮説の分離

```markdown
### FACT
データから確認できる事実

### INFERENCE
事実から合理的に推測できること

### HYPOTHESIS
まだ検証できていない原因仮説

### ACTION
次に確認・実行すべきこと
```

データ不足の場合も分析を止めない。「現時点で言えること＋追加で必要なデータ」を出す。

## 6. 優先順位

**Impact × Confidence × Speed ÷ Effort**

考慮要素：
- 売上インパクト / 利益インパクト
- 実行スピード / 工数
- 再現性
- 顧客への影響
- 在庫状況
- 将来資産になるか

施策は最大5つに絞る。「やった方がいいこと」ではなく「今やるべきこと」を決める。

## 7. 90日実行計画の基本フォーマット

### 0〜30日（基盤・クイックウィン）
現状分析、データ整備、基盤改善、即効性のある改善

### 31〜60日（主要施策実装）
主要施策の実装、テスト、改善

### 61〜90日（検証・横展開）
成果検証、横展開、投資増減判断、次の90日設計

各タスクは必ず：何をする / 誰がする / いつまで / 何を完成させる / KPI / 成功条件 を記載する。
