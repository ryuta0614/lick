# KPIツリー — 楽天EC全体構造

## 最上位KPI構造

```
売上
├── アクセス（セッション数）
│   ├── 楽天検索（自然検索）
│   ├── RPP広告（検索連動型広告）
│   ├── イベント流入（スーパーSALE・マラソン等）
│   ├── ランキング経由
│   ├── R-Mail（楽天メルマガ）
│   ├── お気に入り・再訪問
│   └── 外部流入（SNS・Google等）
│
├── CVR（転換率）
│   ├── 商品ページ品質（画像・説明・レビュー）
│   ├── 価格競争力
│   ├── 送料条件
│   ├── 在庫状況（欠品=CVR0%）
│   ├── クーポン・ポイント
│   └── 流入キーワードの検索意図一致度
│
└── 客単価（AOV）
    ├── 平均商品単価
    └── 一注文あたり購入点数（バスケットサイズ）
```

## KPI計算式

### 基本式
```
売上 = アクセス × CVR × 客単価

客単価 = 平均商品単価 × 一注文あたり購入点数

CVR = 注文件数 / セッション数 × 100  [%]

客単価 = 売上金額 / 注文件数  [円]
```

### 売上成長の分解
```
売上成長 = 新規顧客売上 + 既存顧客売上

新規顧客売上 = 新規顧客獲得数 × 新規客単価

既存顧客売上 = 既存顧客数 × 購入頻度 × 客単価（既存）
```

### 利益構造
```
粗利 = 売上 - 原価

営業利益 = 粗利
          - 楽天システム手数料（売上 × 手数料率）
          - 楽天出店料（月額固定費）
          - RPP広告費
          - アフィリエイト費用
          - クーポン値引額
          - ポイント原資（売上 × ポイント付与率）
          - 送料（実費 - 顧客負担送料）
          - その他変動費（梱包・作業費等）

手数料率の目安（カテゴリ別）:
  - 家電・PC: 2〜4%
  - ファッション: 4〜5%
  - 食品・飲料: 6〜8%
  - コスメ・美容: 4〜6%
  - スポーツ・アウトドア: 4〜5%
  ※ 実際の料率はRMS契約内容を確認すること
```

### 広告効率
```
ROAS = 広告経由売上 / 広告費 × 100  [%]

CPC = 広告費 / クリック数  [円/クリック]

CTR = クリック数 / インプレッション数 × 100  [%]

広告CVR = 広告経由注文数 / 広告クリック数 × 100  [%]

広告粗利 = 広告経由売上 × 粗利率 - 広告費

広告回収率 = 広告粗利 / 広告費 × 100  [%]
```

### 顧客価値指標
```
LTV(売上) = 平均購入単価 × 購入頻度 × 継続期間

LTV(粗利) = LTV(売上) × 粗利率

F2転換率 = 2回目購入顧客数 / 初回購入顧客数 × 100  [%]
  ※ 通常は初回購入から90日以内で測定

F3転換率 = 3回目購入顧客数 / 2回目購入顧客数 × 100  [%]

購入頻度 = 購入回数 / 継続期間（月数）  [回/月]

顧客継続率 = 当期購入顧客数 / 前期購入顧客数 × 100  [%]

平均購入間隔 = 購入間隔の中央値（日）
```

### 商品・在庫指標
```
在庫回転率 = 売上原価 / 平均在庫金額  [回/年]

在庫日数 = 現在庫数 / 日販  [日]

欠品率 = 欠品日数 / 集計期間日数 × 100  [%]

機会損失額（欠品） = 通常日販 × 欠品日数 × 平均単価
```

### 販促効率
```
クーポン値引率 = クーポン値引額 / 売上 × 100  [%]

ポイント原資率 = ポイント付与額 / 売上 × 100  [%]

値引依存度 = (SALE値引 + クーポン値引 + ポイント原資) / 売上 × 100  [%]
  ※ 30%超は警戒水準

イベント依存率 = イベント期間売上 / 全期間売上 × 100  [%]
  ※ 50%超は構造的リスク

クーポン利用率 = クーポン利用件数 / 発行枚数 × 100  [%]
```

## 売上変動の寄与度分解

### 前期比変動の因子分解
```
今期売上 = 今期アクセス × 今期CVR × 今期客単価
前期売上 = 前期アクセス × 前期CVR × 前期客単価

売上変動 = 今期売上 - 前期売上

アクセス要因 = (今期アクセス - 前期アクセス) × 前期CVR × 前期客単価

CVR要因 = 今期アクセス × (今期CVR - 前期CVR) × 前期客単価

客単価要因 = 今期アクセス × 今期CVR × (今期客単価 - 前期客単価)

※ 相互作用項は各要因に按分して処理する
```

### 寄与度（%）
```
アクセス寄与度 = アクセス要因 / 前期売上 × 100
CVR寄与度 = CVR要因 / 前期売上 × 100
客単価寄与度 = 客単価要因 / 前期売上 × 100

合計寄与度 ≒ 売上成長率（%）
```

### 読み方の例
```
例: 売上 -10%（アクセス -15%、CVR +3%、客単価 +2%）
→ アクセス低下が主因。CVR・客単価は改善しており、
  集客さえ回復すれば売上は大幅に戻る構造。
  アクセス施策（RPP・SEO）を最優先に検討する。
```

## 商品レベルのKPIツリー

```
商品売上
├── 商品ページアクセス
│   ├── 楽天検索順位（対象KW）
│   ├── RPP入札状況
│   ├── ランキング掲載
│   └── イベント露出
│
├── 商品CVR
│   ├── 価格（競合比）
│   ├── レビュー数・点数
│   ├── 商品画像・説明
│   ├── 在庫状況
│   ├── 送料条件
│   └── クーポン有無
│
└── 商品客単価
    ├── 商品単価
    ├── バリエーション（大容量・上位モデル）
    └── セット・まとめ買い誘導
```

## KPIベンチマーク（楽天市場参考値）

| KPI | 参考値（目安） | 注意事項 |
|-----|--------------|---------|
| 店舗CVR | 2〜5% | カテゴリ・価格帯で大幅に異なる |
| RPP ROAS | 300〜800% | LTVを考慮すると入口商品は低ROAS可 |
| F2転換率（90日） | 20〜35% | 消耗品は高め、高額品は低め |
| 購入間隔 | カテゴリ依存 | 消耗品30〜90日、耐久財180日以上 |
| 値引依存度 | 〜25% | 30%超は利益構造に要注意 |
| クーポン利用率 | 30〜60% | 配布方法・対象で大幅に変動 |
| レビュー評価 | 4.0以上 | 3.5未満はCVRに悪影響 |
| 在庫日数 | 30〜60日 | カテゴリ・リードタイムで異なる |

※ これらは参考値であり、自店舗の実績値を基準に評価すること。ベンチマークとの乖離ではなく、自店舗の時系列変化を主軸に分析する。
