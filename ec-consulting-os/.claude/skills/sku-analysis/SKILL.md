# Skill: sku-analysis

## Purpose
どの商品に投資すべきか、どの商品から撤退すべきかを明確にする。

## Trigger
- 「商品別の分析をして」
- 「売れている商品・売れていない商品を整理して」
- 「SKUの見直しをして」

## Required Inputs
- SKU別売上CSV（売上・数量・アクセス・CVR）
- 対象期間

## Optional Inputs
- SKU別原価・粗利率
- SKU別在庫数
- SKU別広告費
- 前月・前年データ

## Validation
- SKU IDが一意であるか
- 売上・数量が数値型であるか

## Analysis Steps
1. SKU別に売上・数量・アクセス・CVR・粗利・在庫を集計
2. 売上構成比・粗利構成比を計算
3. 前月比・前年比を計算
4. 分類基準（config.jsonまたはデフォルト）に基づいてSKUを分類
5. 各分類に対する推奨アクションを生成

## Decision Rules

### SKU分類基準（デフォルト）
clients/{client}/context/config.json で上書き可能。

| 分類 | 条件 |
|------|------|
| 成長商品 | 前月比売上+20%以上 かつ 粗利率目標以上 |
| 主力商品 | 売上構成比TOP3 かつ 粗利率目標以上 |
| 高利益商品 | 粗利率が全SKU平均の1.5倍以上 |
| 集客商品 | アクセスが多いがCVRが低い |
| 改善余地商品 | アクセスはあるがCVRが全体平均の50%以下 |
| 低利益商品 | 粗利率が目標の50%以下 |
| 在庫処分対象 | 在庫日数が超滞留閾値以上 |
| 撤退候補 | 売上構成比1%以下 かつ 粗利率マイナス かつ 在庫処分困難 |

## Output Contract
### 必須出力（sku-report.md）

```markdown
# SKU分析レポート

## 商品ポートフォリオサマリー
{全体のSKU数・総売上・総粗利}

## 分類別サマリー
| 分類 | SKU数 | 売上合計 | 構成比 | 推奨アクション |
|------|-------|----------|--------|--------------|

## SKU詳細ランキング（売上TOP20）
| SKU | 商品名 | 売上 | 構成比 | CVR | 粗利率 | 在庫日数 | 分類 | アクション |

## 緊急対応が必要なSKU
{在庫欠品リスク / 超滞留 / 大幅売上低下のSKUを抽出}

## 投資推奨SKU
{成長商品 / 高利益商品のうち広告・LP改善で伸びる余地があるもの}
```

## Missing Data Behavior
- 粗利率不明 → 「粗利率未設定のため売上のみで分析。粗利設定後に再分析推奨」と明記
- CVR不明 → 売上・数量のみで分析

## Human Review
- 撤退候補に主力商品・看板商品が入っていないか確認
- 在庫処分対象の処分方法が現実的か確認

## Test
### 正常系
- 10SKU以上のCSV → 全分類が出力される
- 全SKUが1分類に偏る場合 → 警告を出す

### 異常系
- 売上がすべて0 → 「データ異常の可能性。元データを確認してください」と出力
