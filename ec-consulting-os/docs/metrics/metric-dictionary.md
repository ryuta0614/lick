# Metric Dictionary

すべてのSkillで共通の定義を使用する。独自定義は禁止。

---

## 売上系

| 指標ID | 指標名 | 定義 | 単位 | 備考 |
|--------|--------|------|------|------|
| SALES | 売上 | 返品・キャンセル控除後の純売上 | 円 | 税込/税抜を案件ごとに統一 |
| ORDERS | 注文件数 | キャンセル控除後の確定注文数 | 件 | |
| AOV | 客単価 | SALES / ORDERS | 円 | Average Order Value |
| NEW_SALES | 新規売上 | 初回購入者からの売上 | 円 | |
| REPEAT_SALES | リピート売上 | 2回目以降購入者からの売上 | 円 | |
| LTV | 顧客生涯価値 | 1顧客が生涯にもたらす売上期待値 | 円 | |

## 比較軸の定義

| 比較軸ID | 名称 | 計算方法 |
|----------|------|----------|
| MOM | 前月比 | (当月値 - 前月値) / 前月値 × 100 |
| YOY | 前年比 | (当月値 - 前年同月値) / 前年同月値 × 100 |
| VS_TARGET | 目標比 | 実績値 / 目標値 × 100 |
| CONTRIBUTION | 寄与度 | 各要素変化 / 全体変化 × 100 |
