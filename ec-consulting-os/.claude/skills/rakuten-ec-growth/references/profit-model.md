# 利益モデル — 楽天EC利益計算と機会損失の金額化

## 楽天EC利益計算式

### 基本構造
```
売上
- 原価
= 粗利

粗利
- 楽天システム手数料
- 楽天出店料（月額）
- RPP広告費
- アフィリエイト費用
- クーポン値引額
- ポイント原資
- 送料（実費 - 顧客負担送料）
- その他変動費（梱包・作業・決済手数料）
= 営業利益（概算）
```

### 主要コスト項目の詳細

| コスト項目 | 計算方法 | 備考 |
|-----------|---------|------|
| 楽天システム手数料 | 売上 × 手数料率（2〜8%） | カテゴリによって異なる。実際のRMS契約を確認 |
| 楽天出店料 | 月額固定（プランにより異なる） | 変動費ではなく固定費 |
| RPP広告費 | 実際の消化額 | 日次・月次で把握 |
| アフィリエイト費 | 売上 × アフィリエイト料率 | 通常1〜3%程度 |
| クーポン値引額 | クーポン利用件数 × 平均値引額 | 注文明細から集計 |
| ポイント原資 | 売上 × ポイント付与率 | 基本1%+追加設定分 |
| 実質送料負担 | (送料実費 - 顧客負担送料) × 件数 | 送料無料施策の場合は全額が費用 |
| 梱包・作業費 | 件数 × 単価 | 社内の見積もりを使用 |

### 商品別利益計算テンプレート
```
【商品Aの月次利益シミュレーション】

販売単価:      ¥X,XXX
原価:          ¥X,XXX  (粗利率 XX%)
粗利:          ¥X,XXX

月次売上件数:  XXX 件
月次粗利:      ¥X,XXX,XXX

月次コスト:
  楽天手数料:   ¥XXX,XXX  (売上の X%)
  RPP広告費:    ¥XXX,XXX  (ROAS XXX%から逆算)
  クーポン値引: ¥XXX,XXX  (利用率XX% × 値引額¥XXX)
  ポイント原資: ¥XXX,XXX  (売上の X%)
  送料負担:     ¥XXX,XXX  (¥XXX × XXX件)
  
月次営業利益:  ¥XXX,XXX  (営業利益率 XX%)
```

## 機会損失の定量化（全項目・円建て）

### 1. CVR改善機会

```
CVR改善機会売上（月次）= 月次セッション数 × (目標CVR - 現CVR) × 現客単価

CVR改善機会利益（月次）= CVR改善機会売上 × 粗利率
                        - 追加注文処理コスト（梱包・作業・送料等）

目標CVRの設定:
  Option 1: 自社ベスト期のCVR（直近12ヶ月の最高値）
  Option 2: 同カテゴリ・価格帯の上位25%のCVR水準
  Option 3: 現CVRの +30%（保守的な改善目標）

計算例:
  月次セッション: 10,000UU
  現CVR: 1.5%
  目標CVR: 2.2%（自社ベスト）
  客単価: ¥4,500
  粗利率: 35%
  
  CVR改善機会売上 = 10,000 × (0.022 - 0.015) × ¥4,500 = ¥315,000/月
  CVR改善機会利益 = ¥315,000 × 0.35 = ¥110,250/月
```

### 2. SEO改善機会

```
SEO改善機会売上（月次）= 想定追加セッション × 現CVR × 客単価

想定追加セッション = 対象KWの推定月間検索数 × 目標順位クリック率 - 現流入数

順位別クリック率（楽天検索の参考値）:
  1位: 30〜35%
  2位: 15〜20%
  3位: 10〜12%
  5位: 5〜7%
  10位: 2〜3%
  
計算例:
  対象KW月間検索数: 5,000回
  現在の順位: 8位（クリック率3%）→ 現流入: 150UU
  目標順位: 3位（クリック率11%）→ 目標流入: 550UU
  追加流入: 400UU
  現CVR: 3.5%
  客単価: ¥5,000
  
  SEO機会売上 = 400 × 0.035 × ¥5,000 = ¥70,000/月
  SEO機会利益 = ¥70,000 × 粗利率
```

### 3. 欠品機会損失

```
欠品機会損失売上 = 通常日販（個/日）× 欠品日数 × 平均販売単価

欠品機会損失利益 = 欠品機会損失売上 × 粗利率

通常日販の算出:
  欠品前30日の合計販売数 / 30
  ※ 欠品期間中のデータは除外する（欠品中は販売不可なので実需は不明）

計算例:
  通常日販: 15個/日
  欠品日数: 12日
  平均販売単価: ¥3,200
  粗利率: 40%
  
  欠品機会損失売上 = 15 × 12 × ¥3,200 = ¥576,000
  欠品機会損失利益 = ¥576,000 × 0.40 = ¥230,400
  
  また、欠品中に消化したRPP広告費も無駄コストとして加算:
  欠品中広告費 = 日次広告費 × 欠品日数
```

### 4. 客単価（AOV）改善機会

```
AOV改善機会売上（月次）= 月次注文件数 × (目標AOV - 現AOV)

AOV改善機会利益（月次）= AOV改善機会売上 × 粗利率（追加分の粗利率）
  ※ クロスセルの場合は追加商品の粗利率を使用

目標AOVの設定:
  Option 1: 自社ベスト期のAOV
  Option 2: 送料無料閾値 × 1.1（閾値効果の活用）
  Option 3: バスケット分析から算出した「最頻クロスセルペア」加算後のAOV

計算例:
  月次注文件数: 500件
  現AOV: ¥3,800
  目標AOV: ¥4,500（クロスセル施策後の想定）
  追加分粗利率: 40%
  
  AOV改善機会売上 = 500 × (¥4,500 - ¥3,800) = ¥350,000/月
  AOV改善機会利益 = ¥350,000 × 0.40 = ¥140,000/月
```

### 5. F2転換改善機会

```
F2改善機会売上（月次）= 期間新規顧客数 × (目標F2転換率 - 現F2転換率) × F2客単価

F2改善機会利益 = F2改善機会売上 × 粗利率 - F2施策コスト

F2施策コスト:
  クーポン値引額 = 追加F2転換顧客数 × クーポン値引額
  メール配信コスト = 件数 × 配信単価
  
計算例:
  月次新規獲得数: 200人
  現F2転換率（90日）: 18%
  目標F2転換率: 28%（自社ベスト or 業界上位）
  F2客単価: ¥5,500
  粗利率: 38%
  F2クーポン値引: ¥500/人
  
  追加F2転換数 = 200 × (0.28 - 0.18) = 20人
  F2機会売上 = 20 × ¥5,500 = ¥110,000
  F2機会利益 = ¥110,000 × 0.38 - 20 × ¥500 = ¥31,800/月
```

### 6. RPP広告最適化機会

```
広告機会損失（予算枯渇型）:
  = 予算枯渇後の推定追加インプレッション × CTR × 広告CVR × 広告売上単価

広告無駄費用（低ROAS型）:
  = 広告費 - 広告費 × (目標ROAS / 現ROAS)
  = 広告費 × (1 - 目標ROAS / 現ROAS)

改善後期待利益増:
  = 広告無駄費用削減額（費用削減効果）
  + 削減予算の高ROAS施策への再配分による増分利益
```

## 利益シミュレーション テンプレート

施策実施前に必ず以下の利益シミュレーションを実施する:

```
【施策: ○○の利益シミュレーション】

現状:
  月次売上:     ¥X,XXX,XXX
  月次粗利:     ¥X,XXX,XXX（粗利率 XX%）
  月次営業利益: ¥XXX,XXX（営業利益率 XX%）

施策実施後（想定）:
  追加売上:     ¥XXX,XXX
  追加粗利:     ¥XXX,XXX
  施策コスト:   ▲¥XXX,XXX（クーポン値引・広告費・作業費等）
  追加営業利益: ¥XXX,XXX

ROI:
  = 追加営業利益 / 施策コスト × 100 = XXX%
  回収期間: X.X ヶ月

リスクシナリオ（効果が想定の50%の場合）:
  追加営業利益: ¥XXX,XXX（施策コスト < 追加利益 → 実施可）
               または（施策コスト > 追加利益 → 要再検討）
```

## よくある利益計算の落とし穴

1. **原価不明の場合**: 粗利率を仮定値（例: 30%）として試算し、「原価データがないため粗利率30%と仮定」と明示する

2. **ポイント・クーポンを見落とす**: 売上と粗利だけ見てポイント原資・クーポン値引を見落とすと利益を過大評価する

3. **SALE期の利益計算**: SALE価格での粗利率はSALE前と大きく異なる。必ずSALE価格での粗利率を別途計算する

4. **新規顧客獲得のROI**: 初回購入の利益だけでなく、LTV（粗利）全体で評価する。初回赤字でもLTVが黒字なら投資継続を検討する

5. **欠品コスト**: 欠品中の機会損失売上だけでなく、欠品中に消化したRPP広告費も損失として計上する
